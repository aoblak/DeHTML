# DeHTML Studio

DeHTML Studio is a React and Vite toolkit for common HTML tasks: stripping tags, encoding and decoding entities, formatting markup, and comparing text or code in a diff viewer.

## Get started

Requirements: Node.js 18 or newer, plus npm or yarn.

```bash
npm install
npm run dev
```

The development server runs the application locally. To create an optimized production build, run `npm run build`; output is written to `dist/`.

## Tests

The project uses Vitest and React Testing Library. Run:

```bash
npm test
npm run test:coverage
```
